    Capture notes

      PacketMap / Capture analysisPassive capture analysis · No decryption · No external DNS requests

      Model connection settings

      Saving only updates the connection; it never runs inference. Settings are stored privately on this computer. A blank API key preserves the saved key; it is never returned to this page.

      Origin only, for example http://localhost:1234 or https://models.example.com:443. No API path, credentials, query or fragment. Non-loopback servers require HTTPS; unencrypted LAN HTTP is not supported.

      Each scoped node produces a request. Selected scope, service hints, packet/byte/peer counts, timing, pseudonymous connection evidence and approximate GeoIP city/country labels may be disclosed. Pseudonyms are not a guarantee of anonymity. Remote providers may retain this data and incur charges. Raw captures, IP addresses, captured DNS names, MACs and payloads are not sent to the model.

      OpenAI-compatible mode requires chat completions and JSON-schema output support. Reasoning controls vary by provider. No redirects, proxy fallback, tools or automatic retries.
